# Amazon Clone

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

A modern front-end e-commerce landing page inspired by Amazon, built using plain HTML, CSS, and JavaScript.

This project focuses on recreating the visual style and structure of a familiar shopping experience, including navigation, product sections, promotional banners, and responsive layout behavior.

## Why this project stands out

- Clean, e-commerce-inspired UI design
- Responsive layout for different screen sizes
- Pure front-end implementation without frameworks
- Great example of structured HTML/CSS/JS design work
- Suitable as a portfolio project for product UI development

## Features

- Amazon-style top navigation bar
- Promotional hero banner and deal highlights
- Product card grid with pricing and ratings
- Category and shopping sections styled to match the marketplace aesthetic
- Responsive layout for mobile and desktop screens
- Lightweight static implementation with no build step required

## Tech Stack

| Layer | Technology |
| --- | --- |
| Frontend | HTML5 |
| Styling | CSS3 |
| Interactivity | JavaScript |

## Run locally

1. Clone the repository
2. Open `index.html` in your browser

You can also use a local live preview extension or a small static server if preferred.

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
